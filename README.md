Pillr is a French platform offering intelligence on real‑estate markets using data‑driven analysis. It provides a conversational hub where users can ask natural‑language questions about property prices, taxes, renovation costs, zoning, and investment opportunities. The service aggregates public datasets such as DVF, INSEE, and tax records, delivering scores, cash‑flow estimates, and market signals for investors, agents, and homeowners.

**Areas:** Real Estate · Data Analytics · French · Investment · AI

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Pillr: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
